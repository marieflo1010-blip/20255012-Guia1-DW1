# Guía 5 — Introducción a JavaScript

**Mariela Nicole Flores Arevalo — Carnet 20255012**

Contiene los cuatro ejemplos de la guía y los dos ejercicios complementarios. El ejercicio 1 está integrado en `pages/numeroAleatorio.html`; el ejercicio 2 se encuentra en `pages/pedidos.html`.

## Cómo ejecutar
Abrir `index.html` en el navegador o usar Live Server en VS Code. La página de pedidos utiliza Bootstrap mediante CDN, por lo que necesita conexión a Internet para cargar sus estilos.

## Integración
Copiar la carpeta `Guia5_20255012` en la raíz del repositorio y agregar al portafolio principal un enlace a `Guia5_20255012/index.html`.

## Notas de implementación
- Los indicadores de unidades y monto total reflejan **todos los pedidos registrados**, incluso cuando hay un filtro activo. El filtro solo cambia las filas visibles.
- El archivo `css/style.css` es una versión alternativa: el `.rar` contiene el original, pero no fue posible extraerlo en este entorno. Si es obligatorio utilizar el original, sustitúyelo antes de entregar.
- Se agregaron los identificadores de los botones y el encabezado `h4` para respetar el ejemplo del PDF.
