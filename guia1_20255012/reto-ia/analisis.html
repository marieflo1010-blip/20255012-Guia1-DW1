Estructura y etiquetas HTML
Ya estudiado
  • Estructura base: <!DOCTYPE>, <html>, <head>, <body>.
  • <meta charset>, <title>, <link>.
  • Encabezados <h1>–<h5>, <p>, <a>, <div>, <span>.
  • Listas <ul> y <li> (Clase 2).
  • Atributos como href, class, id.
 Nuevo
  • <header> <nav> <section> <article> <footer>
    Función: etiquetas semánticas de HTML5 que dan significado a cada zona de la página (cabecera, menú, secciones, contenido y pie).
  • <meta name="viewport">
    Función: adapta la escala de la página a la pantalla del dispositivo (diseño responsivo).
  • aria-label / aria-hidden
    Función: atributos de accesibilidad; describen o esconden elementos para lectores de pantalla.
  • <svg> (con path, rect, circle, linearGradient)
    Función: gráficos vectoriales dibujados por código (íconos, logo y gráfica de barras).
  • onclick (JavaScript en el botón de menú)
    Función: ejecuta una acción al hacer clic; JavaScript no es parte de esta unidad.
Formas de incluir CSS y selectores
Ya estudiado
  • CSS embebido con <style> en el <head> (Clase 3).
  • Atributo style — estilos embebidos (Ejercicio 1).
  • Selector de etiqueta, de clase (.clase) y de id (#id).
  • Selector descendente .main-nav a (Clase 4).
  • Selector universal * (Clase 4).
 Nuevo
  • Pseudo-clase :hover
    Función: aplica estilos cuando el cursor pasa por encima del elemento.
  • Pseudo-elementos ::before / ::after
    Función: insertan contenido decorativo generado por CSS (la línea bajo el menú y la textura del hero).
  • :focus-visible
    Función: resalta el elemento enfocado con el teclado (accesibilidad).
  • Carga de fuentes externas (Google Fonts)
    Función: importa tipografías desde un servidor externo (Inter y Newsreader).
Propiedades de texto y color
Ya estudiado
  • color, background-color (Clase 3).
  • font-family, font-size, font-weight, font-style.
  • text-align, text-transform, text-decoration, line-height.
 Nuevo
  • letter-spacing
    Función: ajusta el espacio entre letras (usado en títulos y etiquetas).
  • opacity
    Función: controla la transparencia del elemento (0 = invisible, 1 = opaco).
  • -webkit-font-smoothing
    Función: suaviza el trazo de la tipografía; es una propiedad con prefijo de navegador.
Modelo de caja y maquetación
Ya estudiado
  • width, max-width, height.
  • margin, padding.
  • display (como propiedad).
 Nuevo
  • display:flex + align-items / justify-content / flex-direction / flex-wrap
    Función: Flexbox; organiza y alinea los elementos hijos en fila o columna de forma flexible.
  • display:grid + grid-template-columns
    Función: crea rejillas de filas y columnas (tarjetas, footer, hero).
  • gap
    Función: separación uniforme entre celdas de un flex o grid.
  • position (sticky, relative, absolute) + top / inset / z-index
    Función: posiciona elementos; sticky fija el encabezado al hacer scroll y z-index controla qué queda encima.
  • overflow:hidden
    Función: recorta el contenido que se sale del contenedor.
  • box-sizing:border-box
    Función: incluye borde y padding dentro del ancho declarado.
Efectos visuales y animación
Ya estudiado
  • Colores por nombre y hexadecimal (p. ej. #B01620).
 Nuevo
  • border-radius
    Función: redondea las esquinas de un elemento.
  • box-shadow
    Función: agrega sombras para dar profundidad a tarjetas y botones.
  • transition
    Función: anima suavemente el cambio de una propiedad (color, posición, sombra).
  • transform (translateY, scaleX)
    Función: mueve o escala un elemento sin alterar el flujo del resto.
  • @keyframes + animation
    Función: definen y reproducen animaciones (la entrada del hero).
  • linear-gradient / radial-gradient
    Función: fondos con degradados de color.
  • backdrop-filter:blur() / filter:blur()
    Función: desenfocan; dan el efecto de "vidrio" al header y a la tarjeta del hero.
  • rgba()
    Función: define un color con transparencia (canal alfa).
Variables CSS y diseño responsivo
Ya estudiado
  • Regla CSS: selector + declaración (propiedad: valor) (Clase 3).
 Nuevo
  • Variables CSS: :root { --red: … } + var(--red)
    Función: guardan valores reutilizables (colores, radios) para cambiarlos en un solo lugar.
  • @media (max-width: …)
    Función: media queries; cambian el diseño según el ancho de la pantalla (responsivo).
  • @media (prefers-reduced-motion)
    Función: desactiva animaciones si el usuario prefiere menos movimiento.
  • Unidad ch (p. ej. max-width:13ch)
    Función: unidad relativa al ancho de un carácter, para controlar el largo de línea.
